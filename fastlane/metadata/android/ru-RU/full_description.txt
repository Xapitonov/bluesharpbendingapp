Let's Bend: Настройщик и тренажёр для блюзовой губной гармоники помогает гармонистам точно попадать в бендовые ноты с помощью визуализации в реальном времени.

Приложение полностью бесплатное, без рекламы и может использоваться без регистрации. Звуки захватываются через библиотеку MediaRecorder в виде непрерывного аудиопотока, который анализируется с использованием современных алгоритмов определения высоты тона и отображается в режиме реального времени.

Поддерживаются все распространённые тональности и специальные строи блюзовых гармоник, которые легко настраиваются через меню параметров.

Особенности:
-  Быстрое и точное распознавание музыкальных нот  
-  Несколько алгоритмов определения тона (YIN, MPM и HYBRID)  
-  Поддержка всех популярных тональностей и строев губных гармоник  
-  Регулируемые настройки концертного строя  
-  Визуализация выдувных и втягивающих бендов, оверблоу и овердроу  
-  Настраиваемая уверенность определения высоты тона  

Технические детали (для разработчиков):  
-  Проект с открытым исходным кодом на GitHub  
-  Построен по архитектуре Model-View-Controller (MVC)  
-  Использует систему сборки Gradle  
-  Требует Android 9 (API 28) и выше  
-  Внедрение зависимостей реализовано через Dagger  
-  Логирование через SLF4J  
-  Оптимизирован для конфиденциальности (без сбора и хранения данных)  
-  Часть мультиплатформенного проекта с версиями для десктопа (macOS, Linux, Windows) и веба  

Приложение также доступно на настольных платформах и в виде веб-приложения по адресу https://letsbend.de

Желаем приятной игры и — Let's Bend!
